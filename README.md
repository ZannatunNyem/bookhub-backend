# 📚 BookHub Backend

## 🌐 Overview

**BookHub Backend** is the server side API for the BookHub project. It handles:

- User authentication via Gmail (Firebase Auth)  
- Book data management  
- User specific cart handling  
- Serving API endpoints for the frontend  

This backend works with the **BookHub Frontend** to provide a complete book discovery experience.

---

## 📝 Key Features

✔ Gmail based user authentication  
✔ CRUD operations for books  
✔ Add to cart / remove from cart functionality per user  
✔ RESTful API design  
✔ Integration with Firebase for authentication and data storage  
✔ Cross-Origin Resource Sharing (CORS) enabled for frontend requests  

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **Node.js** | Server runtime |
| **Express.js** | Web framework |
| **Firebase** | Authentication and database |
| **MongoDB / Firestore** | Data storage |
| **CORS** | Allow frontend requests |
| **dotenv** | Manage environment variables |
